# DataBrighten inventory sample

`databrighten-inventory-100.xlsx` is the original 100-row synthetic inventory
workbook published by **DataBrighten**, generated with seed 42. It is included
under [CC0 1.0 Universal](CC0-1.0.txt).

- [Source, data dictionary and license statement](https://databrighten.com/datasets/inventory/)
- [Download from DataBrighten](https://databrighten.com/files/inventory/inventory-100.xlsx?download=1)
- SHA-256: `b65c7019804b980d4e22e44ca021ad0f0bbd8ef26a5ffe99d3b7968ed900adfa`

Upload the workbook with the **Dot** decimal mark. Map `sku` to **SKU**,
`product_name` to **Name**, `unit_price` to **Regular price**, `category`
to **Categories**, and `quantity_on_hand` to **Stock**. The other fields are
supplier inventory data. The export produces 100 simple draft products.
