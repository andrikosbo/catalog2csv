# Security policy

The current 1.x release line receives security fixes. Deploy the latest patch
release and keep PHP, MariaDB or MySQL, and Composer dependencies current.

Use the repository’s **Security → Report a vulnerability** form to send a
private report. Include the version, impact, a minimal synthetic example, and
reproduction steps. Remove credentials, real catalogs and personal data before
submitting. Keep vulnerability details private until a fix is available.

The deployment model is a trusted operator utility behind HTTPS. The
[deployment guide](docs/DEPLOYMENT.md) covers private file placement, the access
password, rate limiting, retention, and deployment verification.
